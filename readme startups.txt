Startups Data Analysis & Profit Prediction
📌 Project Overview

This project analyzes a 50 Startups dataset and builds predictive models to estimate company profit based on R&D Spend, Administration, and Marketing Spend. The analysis includes exploratory data analysis, visualizations, and regression modeling.

📂 Files in the Repository

startups data set.ipynb → Jupyter Notebook with complete analysis & modeling.

50_Startups.csv → Dataset containing startup financial data.

⚙️ Installation & Setup

Clone/download this project.

Install dependencies:

pip install pandas numpy matplotlib seaborn scikit-learn


Run the notebook:

jupyter notebook "startups data set.ipynb"

📊 Features

Data cleaning & preprocessing

Exploratory Data Analysis (EDA)

Data visualization (spending vs. profit trends)

Multiple Linear Regression model to predict profit

Model evaluation using R² score and error metrics

📈 Results & Insights

R&D Spend is usually the most significant predictor of profit.

Marketing Spend contributes but less strongly than R&D investment.

Administration cost shows weaker correlation with profit.
